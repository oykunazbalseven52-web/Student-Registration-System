# Student Registration System

A simple console-based student registration system developed in C++ using the Standard Template Library (STL).

## Features

- Add students with a student number, name, and surname
- List registered students
- Sort students by number, name, or surname
- Delete students by student number
- Insert students at a specific position
- Search students by number, name, or surname
- Exit the application

## Technologies Used

- C++
- STL Vector
- STL Algorithms
- Strings
- Classes

## How to Run

Compile the program using a C++17-compatible compiler:

```bash
g++ -std=c++17 main.cpp -o student
```

Run the program:

```bash
./student
```

## About

This project was developed to practice C++ object-oriented programming and STL operations, including vectors, sorting, searching, insertion, and deletion.
